# 实验记录：小沙自己的"对错判断"（半成：信号有了，判断没稳）

**目标（用户定的优先级）**：先让它有**自己的**对错/是非判断（不靠人教的标签和奖励），再用这个判断去自主学习。

## 结论一句话

**机制方向成立**（无标签、无奖励，靠自己的预测误差确实产生了对错信号：故障时惊讶度尖峰 ×15~×185），
**但"稳定判断"没做到**：低误报 + 5 拍内检测**同时**达不到。**根因是预测器太弱，不是阈值**（见下）。

## 机制

```
它预测"我这一动，下一拍会看到什么"（视觉 32 + 测距 8 + 本体感觉 2 = 42 路）
   预测准 → 对 ；预测错 → 错
真值 = 它自己下一拍的观测（不来自任何标注、任何奖励）→ 所以是"自己的"对错判断
红线 = 自己正常段惊讶度的 95 分位（自校准，没人给它定阈值）
```

## 实测（10 个版本，本机跑；判据：误报 ≤10%、三种故障 ≤5 拍发现）

| 版本 | 关键改动 | ① 正常段误报 | ② 卡死 / 转向反 / 走得慢 检测延迟 | 结论 |
|---|---|---|---|---|
| 1 | 3σ + 30 拍基线 | 12.1% | 未发现 / 2 拍 / 3 拍 | 一惊一乍 |
| 2 | EMA + 4σ + 60 拍 | **0.0%** | 未发现 / 2 拍 / 73 拍 | 太钝 |
| 3 | 加 8 路测距（逐通道归一化） | 12.1% | 未发现 / 2 拍 / 48 拍 | 测距没起作用 |
| 4 | 锥形测距 + 中位数/MAD + 去抖 | 2.9% | 未发现 / 未发现 / 74 拍 | 阈值被抬太高 |
| 5 | 惊讶度取最异常 3 通道（不再平均） | 2.1% | 122 拍 / 未发现 / 67 拍 | 尖峰 ×17 却抓不到 |
| 6 | 阈值改自校准（95 分位） | 2.1% | 未发现 / 未发现 / 未发现 | 平滑后的基线把尖峰盖住 |
| 7 | 判断与校准用同一统计量 | **0.7%** | 未发现 / 11 拍 / 73 拍 | 最接近，仍不达标 |

## 两条真教训（都写进技能了）

1. **判断"错"需要一个不随错的参照**：误差尺度若持续自适应，它会用十几拍把故障当成新常态
   （自我合理化）→ 尖峰被抹平（第 9 版"卡死"只有 ×1.2）。
2. **参照又不能完全冻住**：正常运行时本身有非平稳变化（机体一直漂、动作循环），冻住 → 误报爆炸（第 10 版 44%）。

## 根因：**预测器太弱**（所以再换阈值规则都白费）

正常段惊讶度就有 **×2.2**（相对它自己的均值）—— 说明这个线性预测器**连正常情况都预测不好**。
在弱的预测器上拧阈值，只能在"误报"和"漏报"之间来回换位置，**不可能同时达标**。

## 下一步（正确顺序）

1. **先把世界模型做强**（不是先调阈值）：用皮层/更大的模型做预测、加动作-效果的结构先验、做多步预测。
   判据换成"正常段惊讶度尽量接近 0（预测准）"。
2. 预测器一旦准了，"对错"信号会自己凸显（意外 = 大偏差），阈值就用**简单固定分位**即可。
3. 再回到用户的第二步：**用这个对错信号去自主学习**（自己纠错、自己适应新身体）。
