# 实验记录：自监督表征（两版都失败）

**结论：自主学习的第①件（自监督）这一版做失败，18 版记录在案，别再重复踩。**

## 跑的是什么

- 数据：3000 帧**无标签**数字帧（0~9），只用"同一帧的两种增强视图"或"重建自己"当学习信号，
  全程不用标签、不用奖励。
- 两个目标（都手写反向传播，32→64→32）：
  1. **InfoNCE 对比学习**：同帧两视图应相似、异帧应远离（τ=0.15）
  2. **自编码重建**：从 32 维瓶颈重建输入（MSE）

## 实测（都在本机跑出来，退出码 1 = 判据未达标）

| 表征 | 无人教聚类 纯度 / NMI | 下游认数字（800 次） | 到 25% 用多少次 |
|---|---|---|---|
| 原始眼编码（无自监督） | 32% / **0.27** | **30%** | **586** |
| InfoNCE 对比学习 | 31% / 0.22 | 16% | 未达到 |
| 自编码重建 | 36% / 0.28 | 12% | 未达到 |

两个目标**自身都学会了**：InfoNCE 损失 2.86 → 0.45；重建误差 2.48 → 0.12。

## 为什么失败（关键教训）

1. **在已经高度压缩的手工特征上做表征学习，只会丢信息**。眼编码（32 维分块 DoG）本身已经是
   信息密度很高的手工表征，这一层的"恒等映射"就是最优解；任何代理目标都会把它压坏：
   InfoNCE 的 L2 归一化丢掉"几段亮"的幅度信息，重建目标丢掉细节。
2. **强增强等于明着教它丢身份**：第一版用平移 ±2 + 遮挡当增强，NMI 反而从 0.30 掉到 0.19 ——
   数字身份恰恰藏在位置和形状里。换成只做明暗/噪声/±1 微抖也只是不再恶化（0.27→0.22），仍然没用。
3. **损失下降 ≠ 表征有用**：代理目标被完美优化（损失降到 0.45）只说明它完成了自己的任务，
   跟"下游能不能用"是两件事。判据必须看 **NMI + 下游准确率**，不能看损失。

## 正确做法（下一步）

- 把自监督**搬到原始信号上**：在 24×24 像素上自学前端滤波器（"自己学出眼睛"），
  而不是在 32 维编码后再压一层。
- 或者做**时序预测**（预测下一帧/下一状态）—— 这是动物大脑真正的自监督来源，也天然不会丢信息。
